Producer Licensing Compliance Tracker

An agency with producers licensed in multiple states cannot easily see who is about to lapse. This tracker answers two questions every morning: who expires in the next 60 days, and is anyone still active on a license that already expired.

The Exceptions sheet — lapsed licenses and missing credentials.

How it works

  • MariaDB database on a Debian Linux server I administer
  • Python generates a formatted four-sheet Excel report
  • A cron job runs it every weekday morning

View the code on GitHub — uses generated test data, not real records.
