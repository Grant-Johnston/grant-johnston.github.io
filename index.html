03Projects

Licensing compliance tracker. I built a producer licensing register in MariaDB, filled with generated test data, on a Debian Linux server I set up and run at home. Every Monday at 6 AM, cron runs a Python script that builds a four-tab Excel report: a dashboard, licenses expiring in the next 90 days, exceptions, and the full roster.

The exceptions tab answers two questions an audit asks: is any license still marked active after it lapsed, and is any active producer missing a license?

Source on GitHub. Generated test data, no real producer records.
